# Checklist de Segurança (Vendedores e Compradores)

## Antes de negociar
- [ ] Confira o perfil do vendedor/comprador (tempo de conta, foto, histórico)
- [ ] Para empresa: consulte o CNPJ (verifica_vendedor.py)
- [ ] Desconfie de preços muito abaixo do mercado
- [ ] Peça fotos e vídeos reais do produto

## Na hora de pagar
- [ ] O app do banco mostra o NOME do titular do Pix — confira se bate com o vendedor
- [ ] Prefira pagamento com proteção (Mercado Pago, cartão, etc.)
- [ ] Nunca pague por link recebido no chat; gere o pagamento você mesmo
- [ ] Nunca envie código de verificação (SMS/WhatsApp) para ninguém

## Se suspeitar de golpe
- [ ] Salve prints da conversa e do anúncio
- [ ] Não pague mais nada
- [ ] Chame um admin do grupo
- [ ] Registre BO na delegacia eletrônica do seu estado
- [ ] Denuncie o perfil na plataforma

## Sinais clássicos de golpe
- Preço absurdo de barato
- Vendedor pressionando para fechar rápido
- Pagamento "por fora" do app
- Link curto para pagamento
- Conta criada ontem com fotos de catálogo
